Your app: explore a dataset

Putting it all together, step by step

We build the app that will go online on Day 2. The user:

  1. chooses a dataset (or uploads their own) and loads it
  2. chooses the X and Y variables among the columns of that dataset
  3. clicks to update the plot and the summary

We build it in four steps. Each step is a working app: run it, check it, then move on. The files of each step are in apps/ (05-explore-step1 … 05-explore-step4).

This is the map of the final app: by the end of the page you will know every arrow.

Step 1 · Load a dataset

Nothing new here: a menu, a button, an eventReactive(). We print the first rows to check that the data arrive.

## file: server.R
library(shiny)

server <- function(input, output, session) {

  # 1. LOAD THE DATASET (only when "Load dataset" is clicked)
  dataInput <- eventReactive(input$load, {
    if (input$dataset == 1) {
      rock
    } else if (input$dataset == 2) {
      pressure
    } else {
      cars
    }
  })

  # check that the data arrived
  output$preview <- renderPrint({
    head(dataInput())
  })
}

Step 2 · Menus built from the data

The X and Y menus cannot be written in ui.R: their choices are the column names, and we know them only after the data are loaded. So:

  • in ui.R we reserve an empty slot with uiOutput()
  • in server.R, renderUI() creates the selectInput() and puts it in that slot

3  selectInput("x", "X variable:",

## file: server.R
library(shiny)

server <- function(input, output, session) {

  # 1. LOAD THE DATASET
  dataInput <- eventReactive(input$load, {
    if (input$dataset == 1) {
      rock
    } else if (input$dataset == 2) {
      pressure
    } else {
      cars
    }
  })

  # 2. VARIABLE NAMES (NEW)
  vars <- reactive({
    names(dataInput())
  })

  # 3. DYNAMIC UI (NEW): the choices depend on the loaded data
  output$x_ui <- renderUI({
    selectInput("x", "X variable:",
                choices = vars(),
                selected = vars()[1])
  })

  output$y_ui <- renderUI({
    selectInput("y", "Y variable:",
                choices = vars(),
                selected = vars()[min(2, length(vars()))])
  })

  output$preview <- renderPrint({
    cat("x =", input$x, " | y =", input$y, "\n\n")
    head(dataInput())
  })
}

Load rock, then cars: the menus change with the data. Before the first click the slots are empty, because vars() needs dataInput(), which waits for the button.

Step 3 · The analysis, on demand

A second button, analyze, and a second eventReactive() that freezes the selected columns when it is clicked. The plot and the summary use only these frozen data.

1newdata <- eventReactive(input$analyze, {
  df <- dataInput()
2  df[, c(input$x, input$y), drop = FALSE]
})
1
Runs only when Update analysis is clicked
2
Keep only the two chosen columns. input$x and input$y are text (the column names), so we can use them to select columns

The plot adapts to the type of X: a boxplot if X is categorical, a scatterplot if it is numeric.

## file: server.R
library(shiny)

server <- function(input, output, session) {

  # 1. LOAD THE DATASET
  dataInput <- eventReactive(input$load, {
    if (input$dataset == 1) {
      rock
    } else if (input$dataset == 2) {
      pressure
    } else {
      cars
    }
  })

  # 2. VARIABLE NAMES
  vars <- reactive({
    names(dataInput())
  })

  # 3. DYNAMIC UI
  output$x_ui <- renderUI({
    selectInput("x", "X variable:",
                choices = vars(),
                selected = vars()[1])
  })

  output$y_ui <- renderUI({
    selectInput("y", "Y variable:",
                choices = vars(),
                selected = vars()[min(2, length(vars()))])
  })

  # 4. DATA FOR THE ANALYSIS (NEW): frozen until "Update analysis" is clicked
  newdata <- eventReactive(input$analyze, {
    df <- dataInput()
    df[, c(input$x, input$y), drop = FALSE]
  })

  # 5. OUTPUTS (NEW)
  output$graph <- renderPlot({
    df <- newdata()
    x <- df[[1]]
    y <- df[[2]]
    if (is.factor(x) || is.character(x)) {
      boxplot(y ~ x, xlab = names(df)[1], ylab = names(df)[2])
    } else {
      plot(x, y, xlab = names(df)[1], ylab = names(df)[2], pch = 19)
    }
  })

  output$summary <- renderPrint({
    summary(newdata())
  })
}

Try it: load cars, choose the variables, click Update analysis. Now change the variables without clicking: the plot does not move until you click again.

Last step: a fourth option, Upload data. When it is selected, a file input and the choice of the column separator appear.

Put it in your project

Copy ui.R and server.R of apps/05-explore-step4 into your project my-shiny-app, replacing the old ones, and run it with Run App.

This is the app that goes online on Day 2. Keep the project folder safe.
